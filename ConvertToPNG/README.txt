CONVERTIR PDF
# Para la conversión de PDF a PNG se utiliza el paquete NuGET "PDFtoImage" desarrollado por Sungalia en GitHub. 
# Se instaló el paquete NuGet "PDFtoImage" con "dotnet add package PDFtoImage".


CONVERTIR JPG
# Para la conversión de JPG a PNG se utiliza el paquete "ImageSharp" desarrollado por SixLabors.
# Por qué se eligió ImageSharp? porque es una libreria con alta compatibilidad con Linux, Mac y Windows.
# Se agregó el paquete con "dotnet add package SixLabors.ImageSharp" desde la terminal.
